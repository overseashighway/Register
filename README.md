# Overseas Highway — Digital Directory

A mobile-responsive hub for Overseas Highway websites, social accounts, and digital projects.

## Publish on GitHub Pages
1. Open **Settings → Pages** for this repository.
2. In **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. After GitHub finishes deployment, find the published URL at the top of the Pages settings screen.

The `index.html` page contains search and category filters. Linked GitHub repositories are marked as project links; replace each with its confirmed public website address once available.

## Update links
Edit the `projects` array in `index.html`, and add verified social URLs in the `social` section. Avoid publishing an unverified URL.
